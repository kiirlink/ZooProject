# ZooProject

ZooProject is a simple console application written in **Python** that
demonstrates the basics of **Object-Oriented Programming (OOP)**.

## Features

-   Add new animals
-   Display all animals
-   Feed animals
-   Play with animals
-   Let animals sleep
-   View detailed animal information
-   Interactive console menu
-   Input validation and exception handling

## Animal Properties

Each animal has: - Name - Species - Age - Satiety level (0--100%)

## Technologies Used

-   Python 3
-   Classes and Objects
-   Constructors (`__init__`)
-   Static Methods
-   Lists
-   Loops
-   Match-case statements
-   Exception handling

## How to Run

1.  Clone the repository:

``` bash
git clone https://github.com/kiirlink/ZooProject.git
```

2.  Open the project folder:

``` bash
cd ZooProject
```

3.  Run the program:

``` bash
python3 Animals.py
```
